# Oddium V9.0 — Experience

- Accueil premium à 5 accès : Matchs, Parier, Mes paris, Live, Classement/Profil.
- Image d'accueil IV conservée et les 6 assets championnat conservés dans tous les carrousels.
- Profil joueur : solde, bénéfice net, réussite, historique simple/combiné, records.
- Classement communautaire par bénéfice net.
- Centre Live accessible directement depuis l'accueil.
- Navigation privée avec retour Accueil.
- Ticket combiné conserve son compteur, sa cote totale et ses assets pendant la navigation.
- Aucun appel API n'est déclenché par ces nouveaux boutons : ils lisent le cache SQLite.
