# Oddium V72 — LIVE simplifié

- Suppression du bouton `🔴 Live` du panneau principal Oddium.
- Le panneau permanent `/setup_live` redevient l’unique écran LIVE.
- Ce grand panneau utilise `_live_embed(..., wagered_only=False)` et affiche donc tous les matchs remontés par le moteur LIVE, sans filtre lié aux paris.
- `🎟️ Mes tickets live` reste disponible dans le grand panneau pour retrouver uniquement les paris du joueur en cours.
