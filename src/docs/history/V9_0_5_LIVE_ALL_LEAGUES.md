# Oddium V9.0.5 — Live toutes compétitions

- Le collecteur Live scanne toujours les 6 compétitions supportées dès que le panneau Oddium est installé.
- Le panneau Live n'est plus filtré par les compétitions activées pour les paris.
- Ligue 1, Serie A, Premier League, La Liga, Bundesliga et Ligue des Champions peuvent donc apparaître en Live même si leurs cotes sont désactivées/indisponibles.
- La ligne des sources du panneau mentionne maintenant Sofascore.
