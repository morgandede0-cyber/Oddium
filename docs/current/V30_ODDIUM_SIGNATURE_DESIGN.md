# V30 — Oddium Signature Design

Refonte visuelle sans modification du moteur 5Dollar, des tickets, de l'économie ou du règlement des paris.

- Accueil transformé en hub Oddium cohérent.
- Bet Desk conservé sous forme de carrousel avec les visuels `/assets`.
- Match Board plus lisible avec cotes 1/N/2 directement scannables.
- Live Center devient **Live Arena**, avec une seule présentation canonique partagée entre panneau permanent et interface utilisateur.
- Match Center harmonisé avec la même signature visuelle.
- Tickets, profil et classement reçoivent la même hiérarchie graphique.
- Le bouton Live de l'accueil ouvre désormais aussi les contrôles Détails / Suivre / Mes paris live.
- Tests statiques ajoutés pour empêcher une régression du design et la duplication du Live Center.
