# Oddium V9.0.2 — Live Discovery Fix

- Le collecteur Live est maintenant actif dès que le panneau principal `/setup` est installé.
- Il n'est plus nécessaire d'avoir exécuté `/setup_live` pour découvrir les matchs en cours.
- Les six compétitions actives sont sondées via les sources live gratuites suivant le cycle de découverte.
- Les matchs détectés sont insérés/mis à jour dans SQLite même sans cote PropLine et sans pari en cours.
- Le bouton 🔴 Live de l'accueil peut donc afficher les rencontres en cours de Ligue 1, Serie A, etc.
